# GCC Repo

Working repository for **GCC** — an equity holding and investment company.
This repo holds GCC's digital assets as they grow: the corporate website,
the web app, and operational automations.

## Layout

| Path | What it is |
| --- | --- |
| `web/` | Corporate website (Next.js + TypeScript). See `web/README.md`. |
| _(future)_ | `app/` web application, `automations/`, etc. |

## The website (`web/`)

```bash
cd web
npm install
npm run dev      # http://localhost:3000
```

See `web/README.md` for the full guide, including the list of **draft
placeholders** that must be confirmed before the site goes public (domain,
mission/values wording, director bios, logo).
